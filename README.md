# HR-Analytics-Dashboard# HR Analytics Dashboard

## Overview

This project is an interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze workforce data and generate actionable business insights.

## Features

- Employee Count
- Active Employees
- Attrition Analysis
- Attrition Rate
- Average Age
- Department-wise Attrition
- Education Field Analysis
- Job Satisfaction Analysis
- Gender-wise Attrition
- Age Group Analysis

## Tools Used

- Microsoft Power BI
- Microsoft Excel

## Key Insights

- Monitored employee attrition trends.
- Analyzed workforce distribution across departments.
- Visualized employee demographics.
- Created KPI cards and interactive charts.
